# Desktop keys

The shortcut modifier is Cmd on macOS and Ctrl on Linux.

| shortcut | action |
|---|---|
| Cmd/Ctrl+Shift+P | command palette |
| Cmd/Ctrl+T | new terminal tab |
| Cmd/Ctrl+D | split right |
| Cmd/Ctrl+Shift+D | split down |
| Cmd/Ctrl+Shift+Enter | zoom focused pane |
| Cmd/Ctrl+Shift+W | close focused pane |
| Cmd/Ctrl+1–9 | select tab |
| Cmd/Ctrl+B | toggle Files |
| Cmd/Ctrl+F | find matching rows in visible output |
| Cmd+Shift+O / Ctrl+Shift+N | search project files |
| Cmd/Ctrl+, | settings |
| Cmd/Ctrl+plus/minus | zoom the window |
| Cmd/Ctrl+0 | actual size |
| Ctrl+Cmd+F / F11 | toggle full screen |

The window opens maximised on launch. Terminal font size is set from
**Settings**, separately from the window zoom.

Terminal keys, paste and input methods go to the focused PTY. Unclaimed native
shortcuts remain available to the operating system. Links open with Cmd-click
on macOS or Ctrl-click on Linux; clicking a link logo also opens its target.
Drag pane dividers to resize and scroll over a pane for history.

The old TUI prefix and `[keybinds]` settings do not bind desktop commands.
See [Desktop](desktop.md#controls) for the full control behaviour.
